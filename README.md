# VibeCodingChallenge.Portfolio
Ce projet vise à concevoir un portfolio public en l’espace de deux semaines tout en servant d’expérimentation concrète du vibe coding. L’objectif est d’explorer de façon pragmatique les possibilités et les limites de cette approche en développant le portfolio principalement à l’aide de GitHub Copilot. Le résultat attendu est un portfolio structuré, contenant plusieurs projets de démonstration représentatifs, permettant à la fois de mettre en valeur mes compétences techniques et de documenter l’efficacité réelle du vibe coding dans un contexte de développement orienté produit.
